>プロファイル諸注意<
  ・胸サイズ変更ギミックはプロファイルを問わず非推奨です。ラムネPrefab本体より、"05_FX_BreastController"を削除するかEditorOnlyにしてください。
  ・（上記補足）付属プロファイル・しなのからの変換の場合、プロファイル相性の都合上胸サイズ変更ギミック、胸シェイプキーのBrendshapeSyncを使用しないでください。
  ・設計上、「胸サイズ調整」の衣装同期が難しい場合がございます。ご了承ください。
  ・設計上、肘や膝に貫通が発生する場合がございます。適宜アバターの縮小シェイプキーでの調整をお願いいたします。
  ・"Ramune2template"configにおいて、胸の貫通を簡易的に防止するために"Target Blendshape Settings"の数値を"0.35"としています。問題が発生する場合は、Config Generatorにて正しい数値"0.65"にてお試しください。
    ※詳細は公式ドキュメントを参照ください。https://docs.google.com/document/d/1qNAutpMu3SG068mg5sNDFgNN3ao2GZoW0zG4HbXxyTY/edit?tab=t.0
  ・「ラムネ衣装の他アバター対応変換」において、衣装のコンストレイントが正常に動作しなくなる問題があります。この場合は、"Outer_Shoulder_L/R"&"Outer_UpperArm_L/R"のConstraintを正しく設定し直すと動作するようになりますが、対象アバターの構造によっては難しい場合がございます。こちらの問題に関しての個別の対応は難しいものとさせていただきます。
  ・「ラムネ衣装の他アバター対応変換」において、相性によりストッキングの足の甲の一部が貫通しやすい場合がございます。適宜縮小などをお願いいたします。
  ・「ラムネ衣装の他アバター対応変換」において、相性により腹部からふくらはぎにかけての一部が貫通しやすい場合がございます。適宜縮小などをお願いいたします。（ex.NINE GATES様 ベリル）

>公式プロファイルでのラムネ対応の傾向<
  ・しなの = 全体的に段差になる歪みはなく、安定しています。胸に関して、下部が大きく貫通するためラムネ側のシェイプキー"Breast_Basis_Inside"を25~50程度にするか、いずれかの調整シェイプキーでの調整が必要な場合がございます。また、胸サイズ変更ギミック、BrendshapeSyncが非推奨となります。
  ・桔梗 = 少々段差になる歪みがあります。胸の貫通もありますが、しなの衣装にくらべ小規模です。しなの衣装と同じくラムネ側のいずれかの胸調整シェイプキーで貫通対策が必要な場合がございます。
  ・マヌカ = 大きく段差になる歪みがあります。胸部に関して、かなりぶかぶかになります。貫通は起こりづらいです。場合によってはこちらを使用するとうまくいく場合がございます。（ex.ぴっちりとしたシャツのような衣装）
